Nous avons choisi d'utiliser le pare-feu pfSense pour filtrer le traffic réseau.
La raison principale d'avoir ça au lieu d'avoir seulement Kubernetes, c'est de pouvoir filtrer le réseau également au niveau des autres logiciels que l'on héberge (supervision, sauvegarde, logs, métriques).

On peut aussi s'en servir pour le routage réseau, afin d'exposer nos applications sur internet, ou encore lier les différentes machines du cluster ensemble.

Les modules fournis par les devs ne seront pas dans le même espace Kubernetes que nos autres services, qui seront dans des espaces par thèmes.
