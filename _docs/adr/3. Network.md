# ADR 3: Network architecture

pfSense filters north-south traffic for Kubernetes and the surrounding
monitoring, backup and logging services. Application modules and platform
services use separate Kubernetes namespaces.

Proxmox hosts are connected through the native SDN VXLAN. The design avoids
additional physical interfaces and keeps routing centralized. Kubernetes
application traffic must use encrypted protocols even when the underlay VXLAN
is private.

The firewall pair operates in active-passive mode. Administrative endpoints are
reachable only through the VPN or bastion network, while public game endpoints
use dedicated firewall rules.
