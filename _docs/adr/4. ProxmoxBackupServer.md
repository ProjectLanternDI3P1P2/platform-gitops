# ADR-001: SDN Cluster Backup Strategy via PBS

## Context: Need to implement a centralized and automated backup solution to ensure the resilience of virtual machines in our SDN cluster.

### Decision: 
- Direct bare-metal deployment of Proxmox Backup Server (PBS) packages on the PVE-BACKUP node by adding the repository `http://download.proxmox.com/debian/pbs` to a file located at **/etc/apt/sources.list.d/pbs.sources**, followed by installing the `proxmox-backup-server` package, registering the storage at the Datacenter level to cover the entire cluster, and exposing the service on dedicated port `8007` via the local network interface (`10.4.111.120`).
- Scheduling of a daily backup job at 06:00 in snapshot mode (live/hot backup).
- Configured retention policy: keep-last: 7 (the last 7 daily backups) and keep-weekly: 4 (one backup per week over 4 weeks).
- Implementation of a Verify Job at 07:00 and a Garbage Collection Job at 07:30 on the PBS datastore.

### Consequences:
- Benefits: Automated backups, zero downtime for cluster VMs, and an extended 1-month restore history.
- PBS native deduplication allows storing hundreds of restore points on only 1.8 TB of usable storage mounted on the `vg_backup` LVM.

### Limitations: 
- Storage on an LVM volume without RAID redundancy (risk of total data loss in the event of a physical disk failure).
