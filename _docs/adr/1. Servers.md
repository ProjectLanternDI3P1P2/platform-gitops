# ADR 1: Server layout

The Kubernetes platform uses at least three machines to provide capacity and
fault tolerance: two primary workers and one control-plane or backup node. A
separate DIIAGE Proxmox virtual machine provides additional memory-heavy worker
capacity where appropriate.

Workloads must be spread across physical Proxmox hosts. Replicas of the same
critical service must not share one physical failure domain.

Planned virtual machines:

- `pve1`
- `pve2`
- `pve-diiage`
- `pve-backup`
